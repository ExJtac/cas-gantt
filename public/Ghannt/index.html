MADE FOR THE WORK AHEAD

A schedule you can
actually work with.

Real construction work has dependencies, unreleased areas and material holds. Your schedule should make those visible.

01 / PLAN

One connected schedule.

Edit tasks in a grid or move them on the timeline. Work calendars account for weekends and holidays. Preview the impact before applying a change.

02 / CONNECT

See what comes next.

Link tasks with four dependency types and working-day lag. Cycle checks catch circular plans. Unreleased sections and held tasks stay undated.

03 / KEEP TRACK

Remember the original plan.

Capture named baselines, compare forecast dates, undo edits and review revisions. Export project JSON, task CSV or a printable task report.

BUILDING IN THE OPEN

Standalone first.
More connected next.

We’re proving the core scheduling experience as its own open-source product. Shared workspaces, server storage, team roles and published snapshots are now available. Deeper scheduling and reporting remain on the roadmap.

Integration with Bidlark is planned after the standalone workflow passes acceptance. CAS Gantt does not currently connect to a Bidlark account.

Can I use this for free?

Yes. The source is available under the MIT license. You can run, modify and self-host it, subject to the license and included third-party notices.

Where are my schedules stored?

Browser mode stores projects on this device. Server mode stores them in your signed-in workspace. Browser projects upload only when you import them into a server workspace. Export JSON for backups.

Is this the complete commercial product?

No. This is an early standalone release. Critical-path analysis, nested WBS, XLSX interchange, account recovery, billing and Bidlark integration are not included yet.

How can I help shape it?

Open an issue or contribute code on GitHub. For setup or customization, contact CAS-TX to discuss your workflow.
